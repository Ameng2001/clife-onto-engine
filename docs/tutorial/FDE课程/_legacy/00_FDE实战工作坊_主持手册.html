《C-Life FDE 实战工作坊》 授课流程手册单轨 5 天

《C-Life FDE 实战工作坊》· 授课流程手册（单轨 · 5 天）

拿着这一份，就能从第一分钟讲到结课。 每个时段写明：讲师做什么 / 学员做什么 / 产出什么 / 会卡在哪。 本文件是时间轴；每节课的内容在对应册（工具实操/T*.md）；口径查 _WRITING_BRIEF.md；案例查 案例矩阵_跨项目对照.md。 单轨结构：九步十册，一册 = 一次课。旧十讲的知识与讲师口播稿已并入各册，上课不需要另开文件。 形态参照团队既有《行业数据模型探索工作坊》（STPB 四阶九步）的敏捷引导式，放大到完整能力体系尺度。

〇、三句话说清这个工作坊

  1. 不是十节课，是一个项目。 4–5 个小组各领一个真实命题，五天里把它按 FDE 流程真跑一遍，结课交出一份迷你 FDE 交付包（11 件）。
  2. 每一册 = 一次课 = 三拍：知识（讲什么）→ 案例（看什么）→ 实操（各组在本组命题上真跑，产物落盘）。
  3. 验收不看“讲得好不好”，看学员能不能独立走完认知侧全链条，并且知道自己在哪里必须叫人。
