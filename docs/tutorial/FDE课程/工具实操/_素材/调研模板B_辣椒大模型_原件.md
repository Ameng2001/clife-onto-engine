# 名称:辣椒种植大模型建设调研模板
## 一、定位：【讲清楚大模型的整体定位】
围绕椒农（散户/大户）、辣椒种植合作社/基地、食品加工企业、农资供应商、农业管理部门、育种科研团队、农产品交易平台（农产品交易及收购商）七类核心用户，匹配各自真实业务场景和刚需痛点，实现**一问得方案、一问选品种、一问做决策**，直接支撑辣椒品种销售、标准化种植服务、辣椒品质检测、供应链优化、可验证的产地溯源凭证服务以及辣椒种植数据集等生态数据包服务商业化落地。

## 二、用户及价值：（针对每类用户，明确用户群、本类用户核心刚需、10个以上的典型问句，越多越好）
### 1、椒农 / 散户种植户
- 应用场景：辣椒日常田间管护、病虫害防控、水肥管理、茬口安排、简易提质增产、采收储存、小批量销售、政策补贴申领、建议降本增效。
- 核心刚需：少花钱、少走弯路、病虫害少发生、产量稳、卖价不亏、能拿到种植补贴、识别辣椒种子及品质好坏。
- 细化真实提问：
    - （1）我家地块属于砂质土/黏质土，种线椒、螺丝椒还是朝天椒合适？不用专业仪器怎么判断土壤质地与肥力？
    - （2）我这块地往年死棵严重，不重茬的话最简单低成本的轮作作物选什么？种植密度多少合适？
    - （3）现在5月份，辣椒苗能不能移栽？还能补苗吗？补苗后怎么缓苗成活率高？
    - （4）今年本地降雨、高温期大概情况，辣椒最佳打顶整枝时间在哪几天？
    - （5）我买回来的辣椒种子怎么简单辨别发芽率高低、有没有陈种、有没有掺假？
    - （6）辣椒疫病、炭疽病高发在几月？不用大面积打农药怎么生态防控？
    - （7）辣椒种植补贴、防灾补贴申请条件、流程、每年大概能补多少钱？
    - （8）旱地、低洼地块分别采用漫灌还是滴灌？日常浇水频次和水量如何把控？
    - （9）对比往年，今年辣椒坐果率下降的主要原因是什么？该如何调整管理方式？
    - （10）今年适合储备多少斤辣椒种子明年用？按照我家种植亩数帮我精算一下？
    - （11）露天种植辣椒怎么简单防日灼、防倒伏？
    - （12）小批量采摘的鲜辣椒怎么短期储存不发软、不腐烂？

### 2、辣椒种植合作社/规模化种植基地
- 应用场景：辣椒品种筛选、大棚/露地标准化种植管理、土壤连作修复、田间全程管护、病虫害绿色防控、采收加工、仓储保鲜、批量销售、供应链管控、种植成本核算。
- 核心刚需：快速出适配方案、品种适配性高、种植成本可控、品质达标（商品率高）、减少损耗、卖价稳定提升整体收益。
- 细化真实提问：
    - （1）我所在县域气候土壤条件，主栽什么辣椒品种产量与收益最高？亩均产量、纯收益分别是多少？
    - （2）辣椒大棚种植和露天种植，分别适合什么地形、投入产出比哪种最高？
    - （3）给我出一套简易版一地一方：辣椒品种组合、种植密度、施肥方案、全年管护要求。
    - （4）规模化辣椒种植一般整体种植成本为多少？种子、农资、机械、人工各占多少比例？
    - （5）辣椒商品果验收看哪些核心指标？果长、果径、辣度、含水率达标标准是什么？
    - （6）春茬和秋茬辣椒哪个产量高？春茬、秋茬辣椒定植最佳窗口期分别是什么时段？不同产区种植时间有哪些差异？
    - （7）辣椒采收后分级、预冷、仓储怎么做，能最大程度降低损耗、保障品质？
    - （8）连作多年的辣椒田，如何综合治理土壤问题，杜绝死棵、土传病害？
    - （9）大棚辣椒温湿度控制标准是什么？不同生长阶段（苗期/花期/果期）分别怎么调控？
    - （10）本地有没有已审定、可规模化种植的抗病耐重茬辣椒品种名录？
    - （11）辣椒机械化采收设备怎么选？不同品种适配的采收机型号有哪些？
    - （12）大批量干辣椒仓储，如何防潮、防霉变、防仓储虫害？

- 细化真实提问：
    - （1）这批采购的干辣椒/鲜辣椒从外观、颜色、气味怎么快速评级？大概辣度、水分含量区间多少？
    - （2）制作泡椒、剁椒、辣椒面、辣椒酱，分别适配哪些辣椒品种？如何搭配保证风味统一？
    - （3）鲜辣椒加工前怎么预处理能减少营养流失、提升风味和成品口感？
    - （4）不同产地辣椒（四川/贵州/河南）品质差异在哪？从哪采购性价比最高、货源稳定？
    - （5）怎么快速识别原料辣椒农残超标、霉菌毒素超标，避免成品不合格？
    - （6）辣椒加工过程中辣度损耗原因是什么？如何将损耗控制在合理范围（例如5%）？
    - （7）未来一段时间鲜椒、干椒价格走势如何？何时囤货、加工收益最高？
    - （8）辣椒加工废水、废料怎么处理符合环保要求？资源化利用路径有哪些？
    - （9）不同辣椒品种的加工适配性评分表？哪个品种出粉率最高、哪个品种适合做剁椒？
    - （10）加工车间温湿度怎么控制能延长辣椒原料保质期？
    - （11）如何搭建从种植到加工的全链条溯源体系？溯源数据包含哪些核心内容？
    - （12）研发新型辣椒制品，如何搭配品种实现辣度、香味、口感的最优组合？

## 三、核心场景：(明确核心的场景，每类用户>=1个核心场景)
以 “**智能选种 + 标准化种植 + 品质标准化 + 全产业链智能决策**” 为主线，用多模态大模型打通研发、生产、产品、交易、服务全链路，提升在**种业芯片化、种植方案智能化、辣椒产品标准化、装备自动化、品牌溯源与电商新模式**五大方向的产业化能力。

### 1.辣椒种 “芯片化”：智能选种，周期缩短、品质跃升
- **AI智能育种**：构建**全基因组选择+表型预测+环境适配**模型，把辣椒育种周期从6–8年压缩至2–4年，抗病/耐湿热/高辣度新品种培育效率提升2倍。
- **基因芯片智能化**：升级辣椒专用基因芯片，用大模型解读基因型-表型-环境关联，实现 **“设计型育种”**，定制化培育适合南北方不同气候的专用辣椒品种，支撑 “中国辣椒品种国产化、专用化” 战略。
- **种源“保育繁推”一体化**：数字种业平台+大模型，智能管理辣椒种质资源库，精准预测**发芽率、纯度、适应性**，降低繁育成本15%，提升良种产能30%。

### 2.辣椒种植方案智能化：“一田一方”，精准落地、降本增效
通过大数据分析，实现土壤诊断、品种适配推荐、水肥精准管理方案生成、病虫害绿色防控、种植工艺优化、产量效益预测。
- **种植方案智能配置**：大模型融合土壤、气候、遥感、历史种植数据，自动生成**露地/大棚/高海拔/多雨区**专用辣椒种植方案（品种选择、密度、水肥配比、病虫害防控），应用后**种植成本降20%、水肥节约20%、辣椒产量提2倍**。
- **智能装备+AI决策**：对接辣椒育苗、移栽、采收、水肥一体化智能机械，大模型实时输出**作业参数（灌溉顺序、灌溉频率、灌溉量、施肥方案）**，智能移栽机等装备效率提升**百倍**，人工成本降80%。
- **“辣椒+电商”新模式设计**：大模型优化辣椒产地直供、直播带货的品控标准、包装方案、定价策略，提升**销售效率+溢价空间+ 品牌影响力**，打造“种-产-销”协同产业化样板。

### 3.辣椒产品标准化与价值提升：从“非标”到“数字定价”
- **辣椒品质AI快检**：手机拍照/近红外扫描，1秒输出**辣椒辣度、水分、农残、Vc含量、果形指数**等12项指标，等级自动划分，解决 “眼看手摸”主观定价痛点，交易效率提升**10倍**，溢价空间增加15%。
- **产销精准匹配**：大模型根据收购商**需求品种、辣度、采购量、价格预算**，智能匹配适配的种植基地/椒农，提升交易匹配效率30%，减少中间环节损耗10%。
