# 概览
我们将为广西某工业城市的一个客户开发一个"人力供需撮合平台"，该平台依托于一个人才培训中心，供方为高职院校，需方为各地的用人企业，平台通过整合供方的毕业生数据，同时整合公开市场（各个招聘网站）的需方数据，通过多维度的数据分析和建模，形成针对高职毕业生（含将要毕业的学生）的供需洞察智能应用，解决的是当地高职院校实训内容、专业设置与社会用人企业的需求错配痛点。

# 角色
## 平台的属主和运营方为（广西人才集团下的人才科技公司），依托于人社局提供的"公共技能实训中心"场地开展线上线下运营
## 平台的使用方包括：

* 广西当地的高职院校（利用平台指导学校的专业开设与规划，利用平台替代原有的"访企拓岗"任务，利用平台提供的供需数据洞察进行教育规划和决策，等）；
* 各地（主要为珠三角、长三角区域）的用户企业（发布岗前实训与用工需求，等）
* 当地高职院校的在校学生（报名参加职业培训，搜寻合适的实习机会，等）

# 价值

* 对于供方，可以利用平台进行精准的专业开设规划、通过智能体数据决策替代真实的访企拓岗行为，大大减轻了每年访企拓岗（高职院校去各地企业拜访，拓展本校学生实习渠道的业务）的成本，达到降本增效；
* 对于需方，通过在平台发布的用工需求，一方面可以使企业快速获取实习人才资源、另一方面通过平台线下的人才培训中心进行集中式"缓冲"岗前培训，大大减少了高职人员到企业再进行岗前培训的时间（由平均 3 个月的岗前培训，缩短到 1 个月内，按当地标准每人每月节省 1500 成本）；
* 对当地政府，通过构建高质量高职人才供需数据集，提供了一个"产教融合"的导航仪。它连接了教育端的"供给"与产业端的"需求"，利用大数据为某工业城市甚至广西的职业教育进行"调优"。

# 商业模式

* 平台上通过开展专业技能类岗前培训业务，可直接收取学生的培训费
* 平台通过"校中厂"（如数据标注等业务），可以直接开展劳务外包业务
* 平台可以通过生态入驻（劳务派遣公司），开展获取相关的服务费用

# 平台未来拓展

* 可以拓展针对高职人才的在线职业教育增值业务（类似慕课）
* 可以拓展数据类增值业务（类比：人才领域的万得）
* 可以依托广西特定的东盟地属优势，拓展东盟 + 中国的跨地域产教融合
