一、为什么办这门课（问题陈述）

不是因为"AI 很火，我们也要学"。是因为一个已经发生的事实：

康养项目的完整交付链条 —— 从需求调研到 7 域数智本体建模、到 3835 行可运行插件骨架、到 11 章 / 约 11 万字 / 26 图的对客可研报告 + 2 份附录 docx —— 由 1 名 FDE 带智能体编队完成。 传统模式下这条链条需要：产品经理 + 架构师 + 行业顾问 + 方案经理 + 美工，5 人以上、数周，且各工序之间必然发生信息衰减。

这不是一次侥幸，但它目前不可复制——因为方法在一个人脑子里，不在组织里。 这门课的目的只有一个：把它变成组织能力。

所以本课程的验收标准不是"学员觉得讲得好"，而是：

结课后，一名合格学员能独立承接一个中等复杂度 To-G/To-B 项目的认知侧全链条交付（采集 → 萃取 → 建模 → 设闸 → 交付物），交付质量不低于康养项目基线，且知道自己在哪里必须叫人。

二、课程主张（三条，全课程反复回收）

  1. FDE 的核心资产不是"会用 AI"，是"会把客户的模糊意图压成可执行的结构"。 证据：康养项目 102 个业务事件 → 16 事件簇 → 7 域限界上下文，这一步没有任何模型能替你做判断，模型只能加速你做完。 → 主讲 L1 What①，全程复调，L4 是学员亲手做一遍的地方。

  2. 没有工程化平台的 FDE，只是"更累的架构师"。 证据：7 个域能在同一天并行编译且 7/7 结构校验零悬空引用，靠的是 studio-planner → domain-model → clife-onto-engine 这条固化管线，不是靠个人手速。 → 主讲 L2 ③介绍工具，L8 能力沉淀做三层固化的回收。

  3. FDE 的专业性，一半体现在"敢说不知道"。 证据：18 处规则挂上已核验国标文号，11 处坚决保留 [本地待补文号] 占位不编造，转成一份向某市医保局/民政局/政数局逐项取件的清单。

    内部原话（写在 FDE-citations-待补清单.md 里）："错文号比空缺更有害。" → 主讲 L5 下半场（取证清单），L1 别人怎么做（三档来源纪律）与 L7（demo 诚实边界）各复调一次。

C1–C6 可训练，C7 只能筛选。 这句话在 L1「一人公司 OPC」段第一次讲透（学员还没动手，先建立边界意识），在 L8「OPC 边界回收」段第二次说——那时候学员已经被智能体坑过一轮，才真听得进去。

C0（隐含前置）· 信息采集 不在原七维里，但 v0.3 把它单列成 L3 一整课。 理由：C1–C6 全部建立在"输入是对的"之上。输入错了，下游六维做得越漂亮，错得越远——这是唯一一个错了无法在下游补救的环节。

排期（详表见八课总纲第五节）：

  • 集训档 5 天（推荐 D1 L1+L2 / D2 L3+L4上 / D3 L4下+L5 / D4 L6+L7 / D5 L8+路演）

L1 不产交付物，是刻意的。 v0.2 的病就是把"FDE 是什么"拆碎塞进各操作册（能力模型躲在插件开发册第九节），学员要搞清楚自己在学什么得翻四本。v0.3 把认知层整块提到第一课，末尾 40′ 用 SOP 七阶段点名后面每一课——那 40′ 是认知层与操作层的唯一接口，不许压缩。

五、教学设计规范（每课强制满足）

5.1 统一四段结构（L3–L7 严格适用）

① 目的      一句话：这一课学完能干什么
② 启发      原理 · 方法 · 工具（讲师讲，配课件）
③ 沉浸      真实案例"做对了长什么样"（当场点开看，不是听说）
④ 实操      各组在本组命题上真跑，产物落盘
   └ checkout  达标/警示对照表，组间互评

例外三课：L1 只有 ②（纯讲解）· L2 是 ①②④（可用案例少）· L8 是 ②④ + 路演。

取代 v0.1 的「4:4:2 节奏」。原来的比例是按"讲/练/议"配时间，问题是没有规定"沉浸"这一段——结果讲师容易把案例讲成口头转述。四段结构把"当场点开真实产物"写成硬要求：讲教育督导项目就打开 lib/data.ts 看它真读 79 园 CSV，讲草业项目就打开它的 Mock 关键词路由，两份并排。

5.2 每课三件套（缺一不可）

  1. 1 段实操：含输入材料（真实脱敏件）、明确产物、checkout 对照表（达标项 / 警示项）
  2. 1 个真实反例：取自真实交付实践的失误，不是编的教学案例（见 5.3）
  3. 1 句难听话：直指学员当前能力结构的缺口，不做鼓励式教学

5.3 反例库（取自真实交付实践，按八课分配）

B-1~B-10 取自康养项目；B-11 取自辣椒/草业项目的跨项目模板复用（2026-07-27 新增）。 分配纪律：标「主场」的那一课深讲，其余课只做一句复调，不许重复深讲。

编号 真实失误 表征 引出的原则 分配
B-1 图目计数漂移 _FIG_SPECS.md 标题写"22 张"，表体实际列 26 行；后补的 5-3 / 5-4 / A-1 等图追加到表尾，头部计数未回改 摘要与明细必须有单一真相源；并行产出必须有收口回改动作 L6 主场
B-2 章节编号冲突 35 个分节并行写作，各节自行起标题层级，装配期出现编号重复/跳号 编号权归装配阶段，不归写作阶段（_PLAN.md 已固化此纪律） L6 主场（本课程自己也犯过，见第八节）
B-3 图片路径断裂 正文占位 ../figures/fig-X-Y-slug.png 与实际文件名 slug 不一致 → docx 导出丢图 占位符即契约；slug 必须先定后画，不可事后改名 L8（validate 把"引用文件必须存在"判为 failed —— 校验器替你抓这类错）
B-4 Word 主题色覆盖 导出 docx 时模板主题色覆盖浅色系配图，图文风格割裂 交付物格式与内容是两条独立质检线，都得 FDE 自己走一遍 L6（导出翻车点）
B-5 老龄化率数据张冠李戴 县区七普老龄化率在跨节引用中错配（60+ 与 65+ 口径混用） 关键数字必须锚在 BRIEF 单点，分节作者一律引用不重算 L4 上 主场（该区园数 99/124/79 三源不一是活体）/ L6（引用不重算）
B-6 标准号误标 药食同源目录曾误标为"GB 药食同源目录"；星评标准沿用已废止的 MZ/T 引标准必须核到官方现行版本，"看起来像国标"不等于是国标 L5 下 主场（合规治理段）/ L6 复调
B-7 旅程建模过重 长者旅程初版做"夜间急救"，过重且偏离营收主线，返工改为会员飞轮 建模要服务于业务优先级，不是求全；返工成本记在方法论账上 L4 上 主场 / L1 Why（返工成本进认知杠杆的账）
B-8 越域写入冲动 编译期多次想让 Action 直接 stage_write 他域对象（图省事） 跨域一律 ref/发布，不越界；结构纪律靠校验器而非自觉 L5 上 主场
B-9 SDK 能力想当然 PropertySpec.default、Evaluation 是否导出，编译期存疑未确认，7 域统一留 docstring 不确定就显式挂账，不要靠"应该支持吧"往前推 L5 上（收尾 6 项清单的由来）
B-10 11 处地方文号无解 本地 DIP 细则、助餐补贴办法等 7 处文号 + 4 处企业 SOP 编号公开渠道查不到 诚实边界：留占位 + 锚定上位国标 + 转取证清单，非 BLOCKER L5 下 主场（取证清单）/ L1「别人怎么做」（官方·二手·未获证实三档来源纪律）/ L7（demo 诚实边界）
B-11 模板复用的数字迁移污染（跨项目，非康养项目） 辣椒调研件与草业项目逐段同构、结尾整段逐字相同——是同一模板换领域填的。草业项目"某草业集团30 年 10万+案例/500+标准/200+专利"挂在客户真实积累上、有主；辣椒同样这三个数无主，是模板带过来的。"关系数 40万/200万/500万+"两份亦逐字相同 复用模板可以，复用数字不行：模板迁移必须先把数字与专有名词清零重填，填不出的标 [待客户提供]。每个量化断言都要能答"这数是谁的、从哪来" L3 主场 / L2（复用的正面：调研模板可固化，固化发生在提问结构层）/ L7（复调）

每课至少一个（自查）：L1 → B-7·B-10 复调 · L2 → B-11 正面 · L3 → B-11 主场 · L4 → B-5·B-7 主场 · L5 → B-6·B-8·B-9·B-10 主场 · L6 → B-1·B-2·B-4 主场 · L7 → B-10·B-11 复调 · L8 → B-3 + 全部反例作路演评审标尺。

反例 B-10 是全课程的价值观支点，出现三次不是重复，是复调。 B-11 是 B-10 在"输入端"的镜像：B-10 讲的是查不到就别编，B-11 讲的是别人的数字不是你的数字——一个从别处抄来的"200+ 专利"写进可研，与编造文号是同一性质。二者共用一句判据：空缺可以补，编造无法挽回。 B-11 同时是 L2「平台 = 方法论固化物」的双面教具：正面是调研模板可固化复用，反面就是这条数字污染。L2 只讲正面，污染那面留给 L3 主场。

六、考核方式

项 权重 形式
七次 checkout 累计 40% L2–L8 每课末尾对照达标/警示表，组间互评 + 讲师复评（L1 无实操，不计分）
结课路演 45% 各组把交付包 11 件拼成一份，20′ 答辩：按八维评审卡打分，含 demo 演示 + 诚实说明
反例复盘质量 15% 提交 1 个自己项目里的真实失误，按 B 系列格式写成教学卡

路演三条一票警示（触发即当场指出，不是扣分是"停下来说清楚"）：

  1. 把 Mock demo 说成"已实现" —— 与 B-11 同性质
  2. 交付包内部口径打架（同一个数在两件产物里不一样）—— B-5
  3. 说不出自己在哪里必须叫人（HIL 设点表全是"系统自动"）—— C7 缺位

能力定级（结课发的是等级 + 差距清单，不是合格证）：

级 名称 判据
Lv.1 见习 能在 FDE 指导下承接单一环节
Lv.2 胜任 能独立完成认知侧全链条，交付物需一次复核
Lv.3 主理 能主持项目、设 HIL 闸、对客户承诺负责，并能带 Lv.1

⚠️ 编号纪律（v0.3 起）：定级一律写 Lv.1/Lv.2/Lv.3，不再写 L1/L2/L3——那三个编号现在归课次（L1–L8）。旧讲义与旧课件里的"L1 见习"要当场改口。 L1「能力模型」段第一次讲定级标准，L8「定级」段执行。多数人第一次会停在 Lv.1，这是正常的，装作 Lv.2 才是危险的。

八、元示范：本课程自身就是一次 FDE 交付

在 L6 现场引用——学员刚被"多智能体并行写作口径打架"折磨完，此时讲这个最有效。

这门课的生产过程本身走了同一条 SOP：

  1. 读料建基 → 本体建模总纲 / 验证报告 / citations 清单 / 可研 WRITING_BRIEF / FIG_SPECS / domain-map
  2. 锚定口径 → _WRITING_BRIEF.md（术语表 + 核心数据表 + 案例成熟度 + 商业口径 + 反例分配）
  3. 并行写作 → 十讲拆给 5–6 个子智能体，每个领 1–2 讲，只回摘要不回正文（防上下文爆炸）
  4. 制图并行 → 12 张图与写作同步
  5. 装配与质检 → 术语一致 / 数据一致 / 图文不断链 / 反例分配无重复无遗漏
  6. HIL 闸 → 每个阶段交人确认

而且它真的犯了课上教的错，三次，可以直接当教具：

犯的错 对应反例 怎么发现的
T5a/T5b 拆册后章节号从 6 跳到 8、3 跳到 5 B-2 编号权归装配阶段 装配后通读才发现——正是本课教的那条纪律
v0.2→v0.3 重排时，只改了课程手册，沙盘/案例矩阵/BRIEF 内容口径仍停在旧编号 B-5 单点真相源 全库 grep 才捞出 42 处
定级 L1/L2/L3 与课次 L1–L8 撞号，两套编号在同一份文件里并存 B-5 的变体：编号也是一种口径 本次重写时才暴露；已统一改 Lv.1–Lv.3

讲这三条时别包装成"我们很严谨所以发现了"。真正的点是：这三个错都不是靠细心避免的，是靠"装配期统一收口 + 单点真相源 + 全库检索"这三个机制事后抓到的。 机制能抓，自觉抓不住——这正是 L2 那句"平台 = 方法论固化物"。

外部事实纪律：L1「别人怎么做」段的 Palantir/OpenAI/Anthropic 内容全部联网核证，逐条标来源，查不到写"未获证实"——与本项目不编造文号同一原则（B-10）。

十、改课纪律（下一版怎么动）

  1. 改内容先读 _WRITING_BRIEF.md，数字与案例成熟度一律引用不重算（B-5）。
  2. 改结构先改 00_八课总纲.md，再改课程手册，最后回改本文件与 00_授课流程手册.md——顺序反了必然漏（v0.3 重排就是反着来的，代价是 42 处残留）。
  3. 动了课次编号，必须全库 grep：L[1-8]、第 [0-9]+ 讲、T[1-9]。三套历史编号并存，只改肉眼看到的那几处一定漏。
  4. 新增反例走 B-N 编号，必须在 5.3 表里指定主场课，无主场的反例等于没收编。
