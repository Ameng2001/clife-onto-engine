## 〇、开场（教练宣读，3′）

> 📌 **本组命题推进（贯穿沙盘）**：本讲请用**本组认领的命题**（见 `_贯穿沙盘_分组命题.md`）推进一步——产出 本组命题的**团队编成草案**（1 主理 L3 + N 见习 + 平台组），沉淀进本组「贯穿工作簿」。下方的 💡 启发范例是**标尺、不是模板**：康养项目/教育督导项目/辣椒/草业项目做对了长这样，但你的命题城市/切口/规模不同，**照结构做、别抄数字**。

**🎯 本坊目标**：每人产出 **① 一份 C1–C7 逐维自评矩阵（每维带真实项目证据 + 补课路线）** + **② 一份"1 主理 L3 + N 见习 L1 + 平台组"团队编成草案（含人头/角色/理由，且你自己诚实站位）**。

**🧭 过程方法论（本坊用的 FDE 方法）**：C1–C7 能力矩阵（L0–L3 分级）· 三型自查（架构师/需求分析/项目经理）· **C7 只筛不训（打"是/否/待观察"不打训练分）** · 团队编成三件套（主理/见习/平台组）。

**📏 工作坊纪律（教练宣读）**
1. **启发-执行**：每步先点开"💡启发"看康养项目范例，再动手；不空想。
2. **时间盒**：铃响即停，个人自评/组内互检都守时。
3. **终止铃**：教练铃响，讨论立即停，进下一步。
4. **停车场**：争不出的挂 parking lot，会后再议，不占时间盒。
5. **checkout**：每阶段末对照输出与验收。

**🙌 工作坊宣言（齐读）**：完成大于完美 · 团队大于个人 · 共识大于对错。

## 二、输入材料（可直接发学员）

### 材料 A：FDE 能力判据速查（康养项目锚定，打分时对照）

| 维 | L0 无 | L1 见习 | L2 胜任 | L3 主理 | 康养项目锚点 |
|---|---|---|---|---|---|
| C1 认知萃取 | 没做过事件风暴 | 指导下参与 | 独立主持产出可归域事件集 | 能校准（如 368 份问卷）并做热点 P1–P5 分层 | 102 事件→16 簇→10 热点 |
| C2 结构建模 | 不懂 DDD/OAG | 能读懂一个域 | 独立完成 1 个域过结构校验 | 主导 7 域协同、零悬空引用 | Object 76/Link 75/Rule 47/Action 54 |
| C3 风险设闸 | 没有设闸意识 | 能说该不该设 | 能判"谁按、按错代价" | 设计闸型（站长 HIL/DP-H）定阈值 | 26 个 HIL 点 |
| C4 合规治理 | "像国标就用" | 能核一处是否现行 | 独立挂 citations | 产出可交现场取证清单 | 18 挂国标 + 11 占位不编造 |
| C5 商业建模 | 看不懂财务口径 | 能读懂 | 独立复核内部一致性 | 能搭单店/IRR 模型 | 1.36 亿；21 个月回本；IRR≈15.2% |
| C6 交付物工程 | 只会串行手工 | 按 BRIEF 写 1 节不跑口径 | 组织 ≥10 节并行零冲突 | 定 BRIEF、主持装配质检 | 35 节并行→装配→质检 |
| C7 人的部分 | 会露怯/会编/无政治雷达 | 有潜质待观察 | 稳定表现 | 客户压力下仍"留白不编造" | "错文号比空缺更有害"；11 处占位 |

> C7 提示：C7 **不打 L1–L3 训练分**，只打"是/否/待观察"——它是筛选项不是训练项。给自己填"是"的人，必须附一个真实例子。

### 材料 B：三型自查提示（对号入座，帮你定位最可能卡的维）

- **架构师型**（起点=技术方案）：最可能卡 **C1**——习惯跳过"客户到底要什么"。
- **需求分析型**（起点=访谈）：最可能卡 **C2 + C3**——能采集不能编译、能记录不能设闸，且最易"停 L1 自以为 L2"。
- **项目经理型**（起点=进度/资源）：最可能卡 **C2**——会调度人，压不出可编译结构。

### 材料 C：团队编成参照（康养项目现状 → 可复制结构）

- 康养项目现状：**1 名 FDE + 智能体编队**跑通单点，但"方法在一个人脑子里，不在组织里"，**不可复制**。
- 目标编成：**1 主理 FDE（L3，判断中枢 + 责任终点，C7 过关）+ N 见习 FDE（L1，承接单一环节练六维）+ 平台组（非 FDE，维护 Astra Studio 管线提供杠杆）**。

## 三、分阶段脚本（每步：🔔任务 / 🔔输出 / 🔔难点 + 💡启发范例）

### 阶段一 · 逐维自评 C1–C7（19′）

#### 步骤① · 认领角色型（3′）
> 🔔 **任务**：读材料 B，诚实认领自己最像哪一型（架构师/需求分析/项目经理/其他），并预判自己最可能卡的维。
> 🔔 **输出**：*一句话角色认领 + 预判卡点*（如"我是需求分析型，最可能卡 C2/C3"）。
> 🔔 **难点/注意**：别写"我全维都行"这种自我感觉良好式答案；三型都有明确卡点，逃避认领本身就是信号。

<details><summary>💡 启发 · 点开看康养项目/三型对照范例</summary>

三型卡点对照（讲义难听话）：
- **架构师型** → 卡 **C1**：起点是技术方案，默认"需求已经整理好了"，直接跳过认知萃取。康养项目反面：认知萃取是把 102 个模糊事件压成结构的活，跳过它=在错误地基上盖楼。
- **需求分析型** → 卡 **C2 + C3**：能采集不能编译（记了一堆访谈却压不出 7 域）、能记录不能设闸。**离 FDE 最近，也最容易停 L1 却自以为 L2。**
- **项目经理型** → 卡 **C2**：会调度人、排进度，但压不出可编译结构。

诚实认领的样子："我是需求分析型。我能做访谈纪要，但从没把访谈压成过结构校验的域——所以 C2 我顶多 L1，别装 L2。"

</details>

#### 步骤② · 逐维打分 + 写证据（12′）
> 🔔 **任务**：用材料 A，逐维打 L0/L1/L2/L3（C7 打 是/否/待观察）。**每一维必须写一句"证据"**——你凭哪个真实项目动作打的这个分。
> 🔔 **输出**：*C1–C7 自评矩阵*，7 维全评，每维一句真实证据；C7 若填"是"附一个"敢说不知道/留白不编造"的真实例子。
> 🔔 **难点/注意**：**无证据的分一律作废。** C3/C4/C6 是虚高重灾区——"会写文档"不是 C6 的 L2，"看起来像国标就用"是 C4 的 L0。敢给自己打低分才是专业。

<details><summary>💡 启发 · 点开看康养项目每维"有量化落点"的证据范例</summary>

康养项目之所以每维站得住，是因为每维都有**可验证的量化动作**，而非"我大概会"：
- C1 = **102 事件→16 簇→10 热点**，用 **368 份问卷**校准（不是"我访谈过客户"）。
- C2 = **Object 76/Link 75/Rule 47/Action 54，A 结构 7/7 零悬空引用**（不是"我懂 DDD"）。
- C3 = **26 个 HIL 点**，含站长 HIL 增收闸（阈值占位 0.75）+ 民政 DP-H 发布闸（不是"我知道要设闸"）。
- C4 = **18 处挂已核验国标 + 11 处占位不编造转取证清单**（不是"我引用过标准号"）。
- C5 = **1.36 亿投资、21 个月回本、IRR≈15.2%**（不是"我看得懂财务表"）。
- C6 = **35 节并行→装配→质检零冲突**（不是"我会写 Word"）。

**照镜子的正确姿势**：你打 L2+ 的每一维，都要能对应一个这样"可验证的真实动作"。对不上的，就是 L1 或 L0。

</details>

#### 步骤③ · 圈短板 + 写补课（4′）
> 🔔 **任务**：圈出所有低于 L2 的维，各写一条最小补课动作，对应到具体讲/具体练习。
> 🔔 **输出**：*补课路线*，每个短板一条可下周就做的动作。
> 🔔 **难点/注意**：补课动作要落到"哪一讲/哪个练习"，不能写"多练练"这种笼统话；先分清短板是"没学过"（可训练）还是"没这意识"（近 C7，难训练）。

<details><summary>💡 启发 · 点开看补课路线范例</summary>

- C3 短板（L1）→ "回去把上个项目里所有'按错会赔钱/违规'的操作列出来，用第 6 讲 HIL 四判据逐个过一遍，补一张 HIL 设点表。"
- C4 短板（L0）→ "把我引用过的每个标准号，用第 4 讲方法核到官方现行版；对标反例 B-6（药食同源目录误标、星评沿用已废止 MZ/T）。"
- C6 短板（L1）→ "参与一次 ≥10 节并行编排，感受 B-1 图目计数漂移 / B-2 编号冲突的真实难度，别再把'会写文档'当 L2。"

</details>

### 阶段二 · 起草团队编成草案（14′）

#### 步骤④ · 填编成三件套 + 自我站位（14′）
> 🔔 **任务**：假设下月接一个康养项目量级项目，用模板 2 填：谁当 L3、配几个 L1 各管哪维、平台组几人做什么、**你自己站哪个位子**并说明理由。
> 🔔 **输出**：*团队编成草案*——主理 1 人（含 C7 证据）/ 见习 N 人（各绑单一维）/ 平台组（明确到维护哪条管线）/ 自我诚实站位。
> 🔔 **难点/注意**：**别全员填 L3**（不懂 L3 稀缺性）；**别漏平台组**（漏了会退化成"更累的架构师"，第 5 讲主张二）；把自己填 L3 却拿不出 C7 例子的，编成即失效。

<details><summary>💡 启发 · 点开看编成草案好/差对照</summary>

**目标结构（康养项目现状 → 可复制）**：康养项目现在是"1 人 + 编队"跑通但方法在一个人脑子里、不可复制；要复制就得拆成——

| 角色 | 人数 | 承接 | 判优要点 |
|---|---|---|---|
| 主理 FDE（L3）| 1 | 全维 + 设闸 + 对客承诺 | **必须有真实"留白不编造"的 C7 例子**，不是自封 |
| 见习 FDE（L1）| 2–3 起步 | 各绑单一维（如 C1/C6），在真实项目练 | 数量合理、单维聚焦，不是每人都全维 |
| 平台组 | 1–2 | 维护 planner/domain-model/onto-engine/citations 管线 | 明确到具体管线，不是"技术支持" |

- **好草案**：明确 1 个 L3 且 C7 有实证；L1 各绑单一维；平台组落到具体管线；学员诚实把自己填 L1。
- **差草案**：全员 L3；无平台组；把自己填 L3 却无 C7 证据。

**自我站位诚实的样子**："我现在 C2 才 L1，我站见习位、绑 C6 环节练，L3 让能拿出 C7 例子的老王当。"——承认自己是 L1 不丢人，康养项目那个 L3 也是从压出第一个域开始的。

</details>

### 阶段三 · 组内互检 checkout（6′）

#### 步骤⑤ · 两人换稿互检（6′）
> 🔔 **任务**：两人一组交换自评矩阵 + 编成草案，专挑对方"L2+ 自评的证据"和"L3 站位的 C7 例子"，各记一条最尖锐质疑。
> 🔔 **输出**：*互检记录 + 我要回去补的最大漏洞 1 条*。
> 🔔 **难点/注意**：互检别客气，重点盯"哪个 L2+ 的证据是空话""填 L3 但 C7 例子经不经得起挑战"。

## 四、checkout（验收对照表 · 原评分卡转"达标/警示"）

> 每阶段末 + 收尾各对照一次。四维，每维看"达标线"与"一票警示"。

| 维度 | ✅ 达标线 | ⚠️ 警示（踩了要回炉） |
|---|---|---|
| **D1 自评诚实度与证据质量** | 七维全评、每维配可验证的真实项目证据、敢给自己打低分（尤其 C3/C4）| 无证据、全给自己 L2+、回避短板 |
| **D2 角色定位准确性** | 准确认领三型之一，且正确指出最可能卡的维（与材料 B 自洽）| 未定位或"我全维都行"式自我感觉良好 |
| **D3 补课路线可执行性** | 每个短板对应到具体讲/具体动作，下周可做 | 无补课或"多练练"式口号 |
| **D4 编成草案合理性** | 1 主理 + N 见习 + 平台组结构完整，L3 有 C7 证据，分工对准六维，自我站位诚实 | 缺角色/全员 L3/把自己硬填 L3 无证据/无平台组 |

**评级参照**：四维全达标 = 拿到"能力等级 + 差距清单"（这就是结课评价方式，非合格证）；多数人应诚实停在"我是 L1、卡在 C__"——这是正常结果，装 L2 才危险。
**一票警示**：**把自己填成 L3 却拿不出 C7 真实例子** —— 讲师当众请其举例，举不出者该栏作废重填（这是 C7 筛选项的现场测验）。

## 五、复盘研讨（3 题，教练收口，18′）

1. **（可训 vs 难训）** 你给自己 C3、C4 打了几分？低分是"没学过"（可训练）还是"没这个意识"（近 C7，难训练）？这决定了你补课的性质。
2. **（虚高自查）** 对照三型你最像哪一型？你最可能卡的那一维，是这次自评里你打分最高还是最低的？（很多人卡的维恰恰自评虚高。）
3. **（L3 资格）** 你编成草案里的 L3 是谁？如果是你自己，你的 C7 例子经得起互检挑战吗？如果不是你，说明你现在定位是 L1——你接受吗？

> 教练收口锚点：题 1 指向"C1–C6 可训练、C7 只能筛"（总纲主张四），补课性质取决于短板落在哪侧；题 2 回收"停 L1 正常、装 L2 危险"；题 3 回收"L3 稀缺、从压出第一个域开始"，把补课清单和编成草案接到第 10 讲的 90 天启动计划。

## 六、参考答案要点（讲师版 · 标"讲师专用勿发学员"）

> ⚠️ 讲师专用，勿发学员。

**Exercise 目的**：让学员从"我大概能做 FDE"落到"我现在是 L1、卡在 C__、补课路线是__"。核心是**打掉自我感觉良好**，而非教新技能。多数人应停在 L1，这是正常结果；讲师现场强化"停 L1 正常、装 L2 危险"（总纲原话）。

**自评常见虚高点（重点核查）**：
- C3 风险设闸：几乎所有非 FDE 都会虚高。追问"你上个项目哪个操作按错了会赔钱/违规？你为它设闸了吗？"多数答不出——真实等级应压到 L0/L1。
- C4 合规治理：追问"你引用过的标准号，核到官方现行版了吗？"（引反例 B-6：药食同源目录误标、星评沿用已废止 MZ/T）——"看起来像国标就用"= L0。
- C6 交付物工程：多数人把"会写文档"当 L2，实际没做过 ≥10 节并行零冲突（引 B-1 图目计数漂移、B-2 编号冲突说明并行编排真实难度），应压到 L1。

**三型卡点标准答案**（对应讲义难听话）：
- 架构师型 → C1（跳过认知萃取，默认需求已整理好）。
- 需求分析型 → C2 + C3（能采集不能编译、能记录不能设闸；离 FDE 最近最易停 L1 自以为 L2）。
- 项目经理型 → C2（会调度不会压结构）。

**编成草案判优标准**：
- 好草案：明确 1 个 L3 且其 C7 有真实"留白不编造"例子；L1 数量合理（2–3 个起步）且各绑定单一维在真实项目练；平台组明确到"维护 planner/domain-model/onto-engine/citations 管线"；学员诚实把自己填 L1 而非硬凑 L3。
- 差草案：全员 L3（不懂稀缺性）；无平台组（会退化成"更累的架构师"，引第 5 讲主张二）；把自己填 L3 却无 C7 证据。

**与康养项目证据的强绑定检查**：凡打 L2+ 的维，学员的"证据"要能对应到一个可验证的真实动作，就像康养项目每一维都有量化落点（102 事件 / 26 HIL 点 / 18 挂国标 / IRR≈15.2% / 35 节并行）。空洞证据按无证据处理（D1 直接降档）。

**收口话术**："今天没有人拿到'合格证'，你们拿到的是能力等级 + 差距清单。这正是结课的评价方式。停在 L1 不丢人，康养项目那个 L3 也是从压出第一个域开始的。下一讲（第 10 讲）我们把你这张补课清单和这份编成草案，变成 C-Life 90 天启动计划里认领到你名下的具体行动项。"
