〇、开场（教练宣读，2′）

📌 本环节为研讨环节（不产交付包物件）——本讲就本组命题做启发式研讨，产出记进工作簿的“思考”区即可，不强塞交付物。下方的 💡 启发范例是标尺、不是模板：康养项目/教育督导项目/辣椒/草业项目做对了长这样，帮你把研讨聊到点子上、照结构想，别抄数字。

🎯 本坊目标：就本组命题（或你亲历的一次交付）研讨清楚三件事——① FDE 模式下压缩比大概到什么量级；② 杠杆主要来自 L 结构化 / P 平台 / T 打字快 哪个；③ 哪些环节压不动（1.0×）。 产出是研讨观点 / 一句话共识，不是一张交付表。

🧭 过程方法论（本坊用的 FDE 方法）：工序级人月重估 · 杠杆归因三分类（L 结构化能力 / P 平台固化 / T 打字快）· 压不动环节四判据（涉钱/涉合规/涉责任/方向性返工）。

📏 工作坊纪律（教练宣读） 1. 启发-执行：每步先点开“💡启发”看康养项目范例，再动手；不空想。 2. 时间盒：铃响即停，拆解/重估都守时。 3. 终止铃：教练铃响，讨论立即停，进下一步。 4. 停车场：争不出的挂 parking lot，会后再议，不占时间盒。 5. checkout：每阶段末对照输出与验收标准。

🙌 工作坊宣言（齐读）：完成大于完美 · 团队大于个人 · 共识大于对错。

2.2 杠杆归因三分类（重估每个环节时选一个来源）

  • L 结构化能力：靠 FDE 的判断把混乱压成结构（模型只加速，不替判断）。压缩来自“一个人连续判断，不再跨人重判”。
  • P 平台固化：靠 Astra Studio 固化管线（studio-planner→domain-model→clife-onto-engine→citations→可研）。压缩来自“方法论进平台，不依赖个人状态”。
  • T 打字快：仅生成速度提升。线性、上限低（2–3×）。若某环节压缩主要靠 T，是危险信号。

2.3 压不动环节参照清单（哪些不该算进压缩）

  • 涉钱的拍板判断（如投资/定价口径确认）
  • 涉合规的取证（如向监管逐项取件、核国标文号）
  • 跟客户的责任性对话（承诺、边界、政治敏感度）
  • 方向性判断的返工（见反例 B-7：旅程建模过重返工，压不掉，只能靠事前想清结果避免）

三、分阶段脚本（每步：🔔任务 / 🔔输出 / 🔔难点 + 💡启发范例）

阶段一 · 研讨工序拆法（10′）

步骤① · 选交付、研讨该怎么拆到工序级（2′ 选 + 10′ 研讨）

🔔 任务：就本组命题（或一次你深度参与、能谈出真实人数与工时的交付）研讨：它大致该拆成哪 6–12 个环节？每个环节原本大概几人、几人天、是否跨人交接？边聊边在工作簿“思考”区记要点。 🔔 输出：研讨观点——这次交付的工序拆法草图（6–12 个环节的口头/草稿共识），每个环节能说出个“原人天”的量级感（不求精确、但别拍脑袋）。 🔔 难点/注意：要聊到工序级，别停在“整体三周”这种粗颗粒——不拆到工序级就看不清杠杆来自哪。跨人交接的环节顺手标一下（下一讲研讨复用）。

💡 启发 · 点开看康养项目范例

康养项目认知侧交付若按传统 5+ 人拆，工序级大致是：① 客户访谈/认知萃取（行业顾问）② 需求结构化（产品经理）③ 域/架构设计（架构师）④ 本体/数据建模（架构师）⑤ 可研正文写作（方案经理）⑥ 26 图绘制（美工）⑦ 合规取证/文号核对（行业顾问）⑧ 交付物排版对模板（方案经理）。每条都能挂上“原人天 + 是否跨人”。启发点：拆到这个颗粒度，才看得清“哪条是结构化判断、哪条只是打字”——只报“整体 3 周”看不出杠杆来自哪。

阶段二 · 研讨逐环节杠杆（14′）

步骤② · 逐环节过“三连”研讨（14′）

🔔 任务：对每个环节研讨三连——a. FDE + 智能体模式下这一条大概要几人天？b. 压缩主要来自 L / P / T 哪个（可多选，聊出主导项）？c. 压缩量级大概几倍？ 🔔 输出：研讨观点——各环节压缩大概多少、主导杠杆是 L/P/T 哪个，能对几个关键环节说出“为什么不是打字快”。 🔔 难点/注意：分清 L/P/T 是本讲命门，也是研讨要聊透的点。若某环节压缩主要靠 T（打字快），是危险信号——T 线性、上限 2–3×；真正的结构性压缩来自 L（判断不跨人重判）× P（管线固化）。别把“AI 生成快”一律当成大压缩。

💡 启发 · 点开看康养项目范例
  • 需求结构化（原产品经理 5 人天 → 新 1 人天，L 主导）：压缩来自“102 事件→16 簇→7 域”由同一 FDE 连续判断，不跨人重判；模型只加速、不替判断。
  • 7 域本体编译（原架构师数人天串行 → 新同日并行编译，P 主导）：压缩来自 Astra Studio 固化管线——7 域同日并行编译、7/7 零悬空引用靠平台，不靠个人状态。
  • 可研正文写作（L+P，非纯 T）：35 节并行写作看似“打字快”，实则靠 _WRITING_BRIEF.md 锚定口径（P）+ 结构化拆章（L）才零口径冲突；若只算 T，会把这条的压缩记虚。
  • 26 图绘制（部分 T）：纯生成提速，诚实标 T、压缩比封在 2–3×，不夸大。

启发点：同一份交付里 L/P/T 混在不同环节——把它们分开标，才知道压缩比是“结构性”还是“打字快虚高”。

阶段三 · 研讨压不动项 + 总账（10′）

步骤③ · 研讨哪些环节压不动（6′）

🔔 任务：对照 2.3 清单研讨：本组命题里哪些环节压不动？为什么（涉钱/涉合规/涉责任/方向性返工）？这些环节就该记 1.0×（不压）。 🔔 输出：研讨观点——至少能点出 1 条压不动环节及其理由。 🔔 难点/注意：聊不出任何 1.0× 压不动项 = 还没理解杠杆。研讨要分清“真压不动”（涉钱/涉合规/涉责任/方向性返工，纪律该守）与“不敢让智能体碰”（对平台不信任的短板，该补）——别把后者当成前者。

💡 启发 · 点开看康养项目范例

康养项目里明确压不动、记 1.0× 的环节： - 补 11 处地方文号/企业 SOP 编号（涉合规取证）——查不到就留占位转取证清单，不是智能体能压掉的，得进机关的身份逐项取件。 - 定站长 HIL 置信度阈值 0.75（涉钱+涉责任）——错误增收风险要人担立场，压不动。 - 方向性返工：引反例 B-7——长者旅程初版做“夜间急救”过重、返工改会员飞轮（🟢 已交付真实失误）。这返工压不掉，只能靠事前想清结果避免；它属于“本就压不掉”，不是“不敢让智能体碰”。区分二者是本步的评分眼。

步骤④ · 研讨总账 + 剔 T 反问（4′）

🔔 任务：研讨收口——整体压缩大概什么量级？再追问一句“把打字快（T 主导环节）的贡献折半，压缩还成不成立？”看杠杆是否真来自 L+P。 🔔 输出：一句话共识——整体压缩量级 + 剔 T 后是否仍显著 + 压不动的硬核是什么（我的压缩主要来自 L/P/T 哪个）。 🔔 难点/注意：研讨的好坏不在压缩比喊得多大。能说清“剔除 T 后依然显著、且有明确 1.0× 压不动项”的组，比喊“全能压 10×、没有压不动项”的组理解得深——后者恰是没理解杠杆。

💡 启发 · 点开看康养项目范例

康养项目的量级是 5+ 人 / 数周 → 1 人 / 同量级并行，这是结构性变化，不是打字快：即便把所有 T 主导环节（如 26 图生成）压缩折半重算，总压缩比依然显著——因为主杠杆是 L（102 事件→7 域，判断不跨人重判）× P（7 域同日并行编译、7/7 零悬空引用靠固化管线）。一句话结论范本：“我的压缩主要来自 L+P，压不动的硬核是 涉合规取证（11 处文号占位）+ 方向性返工（B-7）。”引 BRIEF 主张 1、2。

四、checkout（研讨深度对照）

每阶段末 + 收尾各对照一次。这是研讨环节，checkout 看的是“研讨深度”——有没有落到本组命题、有没有真观点，而不是有没有交出一张表。四维，每维看“到位线”与“没聊透的信号”。

维度 ✅ 研讨到位 ⚠️ 没聊透（信号）
D1 落到本组命题 研讨是就本组命题（或亲历交付）聊到工序级，不是空谈概念 只停在“整体三周”粗颗粒，或聊的是泛泛而非本组命题
D2 分清杠杆来源（L/P/T） 对关键环节有自己的判断、能说清为何不是打字快，不是照抄范例 全部归“AI 快”、不分来源，L/P/T 混作一团
D3 诚实承认压不动 主动点出涉钱/涉合规/涉责任/方向性返工的压不动环节，不注水 声称“全能压”、聊不出任何一条压不动项
D4 结论可辩护 有一句“剔 T 后仍成立、杠杆来自 L+P”的可辩护共识 只喊压缩比虚高、主要靠 T，自相矛盾

评级参照：四维都聊透、剔 T 后仍成立 = 真懂杠杆（L2 潜质）；方向对但论证弱 = L1 见习；研讨里只有“全能压 10×、无压不动项” = 认知没到位。 没聊透的头号信号：全程只喊“AI 快”、没分清杠杆来源、也聊不出任何一条压不动项 —— 说明没理解杠杆来自哪、也没理解 HIL 硬判据（第 3/6 讲）。研讨若停在这里，教练要把话头拽回 L/P/T 和压不动项上。

五、复盘研讨（3 题，教练收口，18′）

  1. （杠杆归因） 你的压缩比里，最大那块来自“结构化能力(L)”、“平台固化(P)”还是“打字快(T)”？若主要来自 T，说明什么？
  2. （压不动 vs 不敢碰） 你标“压不动”的环节，是真压不动，还是你不敢让智能体碰？两者区别在哪？
  3. （无平台反事实） 同样这份交付，若你没有 Astra Studio 平台、只有一个人 + 通用大模型，压缩比会掉到多少？

教练收口锚点：题 1——主要靠 T = 没理解杠杆（T 线性、上限 2–3×）；康养项目是 5+ 人→1 人的结构性变化，靠 L×P（引 BRIEF 主张 1、2）。题 2——真压不动 = HIL 硬判据（涉钱/涉合规/涉责任/方向性返工，纪律该守）；不敢碰 = 对平台不信任的短板（该补）；引 B-7：旅程返工是方向判断错、压不掉，属“本就压不掉”不属“不敢碰”。题 3——会大幅掉且质量不可控，正是主张 2“没工程化平台的 FDE 只是更累的架构师”（7 域同日并行编译、35 节零口径冲突靠平台），预告第 5 讲“无平台重做康养项目成本推演”。

六、参考答案要点（讲师版 · 标“讲师专用勿发学员”）

⚠️ 讲师专用，勿发学员。

  • 研讨题 1：主要靠 T（打字快）= 没理解杠杆。打字快线性、上限 2–3×；康养项目是 5+ 人→1 人的结构性变化，来自 L（102 事件→16 簇→7 域，模型不替判断）× P（7 域同日并行编译、7/7 零悬空引用靠固化管线）。引 BRIEF 主张 1、2。
  • 研讨题 2：真压不动 = 涉钱/涉合规/涉责任/方向性返工（HIL 硬判据，第 3、6 讲）；不敢碰 = 对平台不信任的能力缺口。前者是纪律（应该守），后者是短板（应该补）。别混。引反例 B-7：旅程返工是方向判断错，压不动，只能靠事前想清结果避免——它不属于“不敢碰”，属于“本就压不掉”。
  • 研讨题 3：会大幅掉，且质量不可控——正是主张 2“没工程化平台的 FDE 只是更累的架构师”。7 域同日并行编译、7/7 零悬空、35 节并行零口径冲突（靠 _WRITING_BRIEF.md 锚定），换成裸大模型都保不住。此题是第 5 讲“无平台重做康养项目成本推演”的引子，可预告。
  • 评分校准：警惕“压缩比越大分越高”的直觉。真正高分表的特征是——有明确的 1.0× 压不动项、剔除 T 后压缩比依然成立。把 D4 结论可辩护当主锚：一张诚实标了压不动、承认返工压不掉的 3× 表，胜过一张全能压的 10× 表（对应“一票警示”）。
  • 口径纪律：所有康养项目数字引用 2.1 基线锚，不重算不改口径（BRIEF 第二节 / 反例 B-5 精神）。
