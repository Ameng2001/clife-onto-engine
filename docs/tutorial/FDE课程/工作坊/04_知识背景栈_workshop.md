## 〇、开场（教练宣读，4′）

> 📌 **本组命题推进（贯穿沙盘）**：本讲请用**本组认领的命题**（见 `_贯穿沙盘_分组命题.md`）推进一步——产出 本组命题的 **事件集→画像→旅程→10 热点 + 限界上下文域草案 + 一个核心域的五要素本体草案 + 商业模式画布**，沉淀进本组「贯穿工作簿」。下方的 💡 启发范例是**标尺、不是模板**：康养项目/教育督导项目/辣椒/草业项目做对了长这样，但你的命题城市/切口/规模不同，**照结构做、别抄数字**。

**🎯 本坊目标**：针对你自己，产出 **① 一张七角色定级表**（L1 见习／L2 胜任／L3 能独立交付，每级都举得出证据）+ **② 一张七维雷达**（叠康养项目基线，看清塌陷的那一两根轴）+ **③ 一页最弱栈应用笔记**（读完一节经典/范本，落到"下周就能对项目做的可执行动作"，不是读后感）。

**🧭 过程方法论（本坊用的 FDE 方法）**：七角色—七经典栈 · 定级三档口径（举不出交付级证物最高只能 L2）· 七维雷达自诊 · **启发-执行两拍**（先看康养项目七栈实证，再对自己诚实定级）。

**📏 工作坊纪律（教练宣读）**
1. **启发-执行**：每步先点开"💡启发"看康养项目范例，再动手；不空想、不攀比级别。
2. **时间盒**：铃响即停，个人定级/小组互评都守时。
3. **终止铃**：教练铃响，讨论立即停，进下一步。
4. **停车场**：争不出的挂 parking lot，会后再议，不占时间盒。
5. **checkout**：每阶段末对照输出与验收。

**🙌 工作坊宣言（齐读）**：完成大于完美 · 团队大于个人 · 共识大于对错。

> 这个练习残忍的地方在于：它不评你"读过多少书"，评你**每一栈能不能举出交付级的证据**。举不出，就是 L1，别自封 L3。

### 2.3 定级口径卡（贴手边）

> 每一栈只有一个级别，按最诚实的证据打：
> - **L1 见习**：读过 / 学过，能看懂别人的产物，但没独立产出过，或产出过但没过验收。
> - **L2 胜任**：能在有人带 / 有模板的情况下产出，但离"独立跑完交付"还差一口气（对不齐 2.1 的判据）。
> - **L3 能独立交付**：**命中 2.1 该栈的"能交付"判据，且举得出一件真做过的交付级证物**（不是"我理解这个概念"）。
> 举不出交付级证物却想填 L3 —— 停，那是 L2。

### 2.4 你要带来的输入

一个你正在做或最近做过的真实项目（To-G / To-B 皆可），以及你手上任何能当"证据"的产物（事件清单 / 域图 / 本体代码 / 画布 / 现金流表 / 可研节 / 取证清单）。没有在手项目的，用康养项目二期"微康养 60 站点运营方案"做替身，对着 2.2 基线诚实自评。

## 三、分阶段脚本（每步：🔔任务 / 🔔输出 / 🔔难点 + 💡启发范例）

### 阶段一 · 七角色逐个定级 + 画雷达（28′）

#### 步骤① · 逐栈定级（18′）
> 🔔 **任务**：对照 2.1 判据与 2.3 口径卡，给七个角色**逐个**打 L1/L2/L3，填进 2.5 表①。每栈都在"定级证据"栏写清你这一级的证据——L3 必须是一件真产物（哪个项目的什么东西），L1/L2 也要写"卡在哪一步上不去"。
> 🔔 **输出**：*七角色定级表填满七行*，每个 L3 都绑一件交付级证物，L1/L2 都写明卡点。写不出证据的一律降到 L1 并标"❓待验证"。
> 🔔 **难点/注意**：**建模栈（②③）易被高估**——若你②③打 L3、而④⑤⑥打 L1/L2，八成是把定级打虚高了。栈③ L3 要"五要素写全并编译通过"，栈② L3 要"过结构校验"，没有就降。别用"我理解这个概念"顶替真产物。

<details><summary>💡 启发 · 点开看康养项目七栈证物长什么样</summary>

拿康养项目这条已交付的链当"L3 证据"标尺，逐栈看"交付级证物"是什么颗粒度：
- **栈① 产品 L3**：不是"我会画用户画像"，是 **102 事件 → 16 簇、7 画像用 368 份问卷校准**、每个画像特征指得到问卷来源——事件**可归域**不是流水账。
- **栈③ 本体 L3**：不是"我懂 OAG"，是 **OAG 76/75/38/47/54/26 五要素写全、3835 行 + 21 YAML、7/7 py_compile ✓**，且讲得清 OAG≠RAG（防幻觉在执行层）。
- **栈⑤ 财评 L3**：不是"我知道 IRR 是啥"，是能独立复核 **某工业城市 27,056 FP → 4,839 万** 这条量价链自不自洽、康养项目 **IRR 15.2%（第 9 年）** 与回本年对不对得上。
- **栈⑦ 合规 L3**：不是"我知道要合规"，是 **18 处挂已核验国标 + 11 处占位不编造**，面对查不到的文号默认"留占位转取件"。

对照标尺你会发现：多数人手里的证物在栈②③还够得着，到④⑤⑥就只剩"我理解概念"——那就是 L1/L2，别填 L3。

</details>

#### 步骤② · 描七维雷达（6′）
> 🔔 **任务**：把七个级别（L1=1、L2=3、L3=5，或用 0–5 细分）描到 2.5 雷达图上，叠上 2.2 康养项目基线参考线。
> 🔔 **输出**：*两条线的七维雷达*——（我）当前级别 + （康养项目基线）参考线，一眼能看出最短那根轴。
> 🔔 **难点/注意**：别"以强掩弱"——用一根强轴把整张图撑得好看，掩盖塌陷轴。雷达是用来**暴露**短板的，不是用来自我表扬的。

<details><summary>💡 启发 · 点开看"塌陷长什么样"</summary>

技术出身的人画出来的雷达，典型形状是**②③本体/DDD 两根轴顶到 L3，④⑤⑥商业/财评/交付物三根轴塌到 L1**——像一把只有一边有齿的梳子。康养项目基线则是七根轴都在 L2–L3（因为它是一条走完 S1–S7 的完整交付）。你和基线之间的缺口，几乎全在④⑤⑥这一侧。看清这个形状，就看清了"会建模 ≠ 是 FDE"。

</details>

#### 步骤③ · 认领最弱栈（4′）
> 🔔 **任务**：圈出**最短的那一栈**（并列则选对你项目最要命的那一栈），它进阶段二精读。
> 🔔 **输出**：*认领结论一句*——"我的最弱栈 = 栈__（角色：____），比康养项目基线低 __ 级"。
> 🔔 **难点/注意**：多数技术出身的人塌在**④商业模式 / ⑤财评 / ⑥交付物**——如果你圈的最弱栈落在②③建模，先自查是不是"避重就轻挑了个假短板"、把真塌陷的④⑤⑥打虚高了。

<details><summary>💡 启发 · 点开看"假短板"陷阱</summary>

常见的自欺：一个人财评栈其实从没算过 IRR（真 L1），却因为"我商业模式画布画得挺熟"把④⑤都打了 L2，转头把"最弱栈"认领成了②DDD（其实②他有过结构校验证物、是 L3）。结果精读了一节自己本就会的东西，回避了真正算不出账的⑤。**认领口径**：最弱栈应该是那根你"举不出任何交付级证物"的轴——通常最疼的那栈，就是对的那栈。

</details>

### 阶段二 · 最弱栈精读一节 + 应用笔记（20′）

#### 步骤④ · 翻开经典/范本攻一节（12′）
> 🔔 **任务**：翻开最弱栈对应经典/范本（见 2.1）的**一节**——不求读完整本，就攻一节。
> 🔔 **输出**：*一节精读的核心方法 3 句话*，填进 2.5 应用笔记的"核心方法"栏。
> 🔔 **难点/注意**：攻的这一节要能直接对上你的塌陷点，别挑最好读的一节划水。

<details><summary>💡 启发 · 点开看各栈"攻哪一节"的范例</summary>

- **栈②**：读《领域驱动设计》"限界上下文"或"上下文映射"章，回答"我项目里两个域到底是引用还是发布"。
- **栈③**：读 **`clife-onto-engine` README + `docs/02-oag-positioning`（OAG≠RAG 纠偏卡）+ methodology `07`/`09`**，讲清"防幻觉在执行层不在检索层"，再对标 Palantir 官方文档建立坐标。
- **栈④**：**把康养项目 BP 财务测算 Excel 逐列看懂一遍**（营收假设→成本→EBITDA→净利→现金流→IRR/回本），并能复述 EBITDA/IRR 的定义。
- **栈⑤**：补 NESMA 五类功能计数（ILF/EIF/EI/EO/EQ）一节，能对上"27,056 FP 是怎么数出来的"。
- **栈⑥**：精读一份中标可研的目录 + 一章正文，看它章节结构与政务文风。
- **栈⑦**：跟着"全国标准信息公共服务平台"核一条标准的现行/废止（示范 B-6：药食同源误标 GB、星评沿用已废止 MZ/T 都是没核到官方现行版惹的祸）。

</details>

#### 步骤⑤ · 写应用笔记（8′）
> 🔔 **任务**：用 2.5 应用笔记模板，产出**一页**笔记。至少写出一个"下周就能对康养项目 / 我的项目做的具体动作"，且带可验收标准。
> 🔔 **输出**：*一页应用笔记*——含核心方法、"怎么用到我的项目"、≥1 个可执行动作 + 验收标准、补到 L3 的时间承诺。
> 🔔 **难点/注意**：**必须落到可执行动作，不是"我学到了……"**。反例："多学点商业模式"（泛）；正例："本周把我项目的 BP 收入来源栏，从'靠政府买单'改写成三元支付式的具体付费方+机制，验收=每一笔收入都填得出谁付钱、按什么单价"。

<details><summary>💡 启发 · 点开看一页合格应用笔记（栈⑤财评范例）</summary>

| 项 | 填写 |
|---|---|
| **我的最弱栈** | 栈⑤ 财评 |
| **读的哪一节** | NESMA 功能点计数 · 五类要素（ILF/EIF/EI/EO/EQ）一节 |
| **核心方法（3 句）** | 软件开发费 = 功能点规模 × 单价，量价分离；功能点按五类要素据实数，不是拍模块数；IRR/回本要和营收−成本−EBITDA 链条自洽。 |
| **我的项目怎么用** | 对着康养项目"484 条目 → 27,056 FP → 4,839 万"这条链，把我项目报价单里的"功能点"重数一遍，判它是不是虚高。 |
| **下一步动作①** | 动作：独立复核我项目一份财务口径的内部一致性（营收−成本能否推出 EBITDA、IRR 与回本年是否自洽）；验收：能指出至少一处口径不自洽或确认全链自洽，并说清依据。 |
| **补到 L3 时间** | 3 个月内能独立看一份定制软件报价、判功能点虚不虚、单价有没有据。 |

对照它，你就知道"读后感"和"应用笔记"的差别：应用笔记每一行都能被验收。

</details>

| **D3 应用笔记可执行** | 落到具体动作 + 验收标准，绑定康养项目 / 自己项目，明显不是读后感 | 通篇"我学到了 / 很有启发"，零可执行动作 |

## 五、复盘研讨（3 题，教练收口，24′）

1. **（短板暴露）** 你七维里最短的那根轴是哪个角色？它塌了会让康养项目这条链断在哪一段？（提示：栈⑤塌 → 出得了本体盘不出账、过不了财评，方案签不了字；栈⑥塌 → 脑子里有本体、客户手里没文件；栈⑦塌 → 挂错文号，一份方案在客户处失信。）
2. **（以强掩弱）** 七个角色里，哪两个你以为强、其实是靠另一个凑的？（提示：常见是用栈①产品的"会讲故事"掩盖栈⑤财评的"算不出账"；用栈⑥交付物的"文笔好"掩盖栈④商业的"模式空"。）
3. **（补课收口）** 给你三个月只能补一个角色，补哪个、读哪本经典/范本、怎么验收补上没有？（验收要落到康养项目级动作，如"能独立复核一份 IRR 口径一致性 + 看懂一份 NESMA 功能点报价"，不是"我把康养项目 BP Excel 打开看了一眼"。）

> 教练收口锚点：题 1 指向"七套方法论是这门课**唯一能靠努力补上的部分**"（区别于 C7 补不了）；题 2 让学员当众点出自己那一对"以强掩弱"，敢承认给正向反馈；题 3 收口——短轴可量化、可补、藏不住，但也要认得出"这里该请真专家了"（复杂财评、重大法律风险），这也是能力半径的一部分。

## 六、参考答案要点（讲师版 · 标"讲师专用勿发学员"）

> ⚠️ 讲师专用，勿发学员。

- **本 Exercise 无标准答案，评的是"诚实 + 可执行"，不是级别高低。** 一个全栈 L1 但每条证据都诚实、补课路线可验收的学员，得分应高于一个自封五个 L3 却举不出证物的学员。把这条讲透，否则学员会互相攀比级别。

- **常见塌陷栈（重点抓 ④⑤⑥）**：技术出身的学员几乎必塌在这三栈。
  - **栈⑤财评**是最普遍、最致命的塌陷——多数人从没算过 IRR、不知道 NESMA 五类功能怎么数、看不懂"27,056 FP → 4,839 万"怎么推。这一栈填 L2 以上的，追问一句"你独立复核过一份财务口径的内部一致性吗"，答不出当场降级。
  - **栈④商业**塌得隐蔽：很多人能画出九宫格，但"收入来源"格填的是"靠政府买单 / 靠融资"这种空话——够不到判据（具体付费方与机制），最高 L2。三元支付、单店 73 万/21 月回本这种颗粒度才是 L3。
  - **栈⑥交付物**塌在"没独立组织过 ≥10 节零口径冲突的并行写作"，或"交付物格式没对齐过客户模板"。

- **常见"以强掩弱"（D2 一票警示的主战场）**：
  - **产品掩财评**：用栈①"会做事件风暴、会讲用户故事"的强，掩盖栈⑤"算不出账"的塌。表现为把最弱栈选成了别的，回避财评。
  - **文笔掩商业模式**：用栈⑥"文字好、会写方案"掩盖栈④"商业模式空"。一份文笔漂亮但收入来源填不出付费方的方案，是典型。
  - 抓法：让学员在研讨题 2 里当众点出自己这一对"以强掩弱"，敢承认的给正向反馈。

- **建模栈（②③）反被高估**：本讲主旨就是"建模只是七分之二"。若学员最弱栈落在②③、而④⑤⑥填了 L2/L3，八成是定级打虚高——用 2.1 判据逐条压：栈③ L3 要"五要素写全并编译通过"，栈② L3 要"过结构校验"，没有就降。

- **一票警示落地**：自封 L3 举不出交付级证物 = 本坊不通过。对应讲义难听话——"你能交出 7 域本体、3835 行骨架很好，那是栈②栈③；客户问你总投资多少、IRR 几年回本，你答不出，就只是个更贵的建模师。"

- **与康养项目锚点对齐检查**：学员引数字须用 BRIEF 口径（368 问卷 / OAG 76·75·38·47·54 / 27,056 FP·4,839 万 / IRR 15.2% / 73 万·21 月 / 18 挂标·11 占位）。引错当场纠正，示范 B-5"锚在单点不重算"。若学员把草业项目/辣椒效益数字当实测引用，纠正为"方案目标值"；顺带用 B-6 标准号误标（药食同源误标 GB、星评沿用已废止 MZ/T）提醒栈⑦"引标准必核到官方现行版本"。

- **研讨题 3 收口**：呼应讲义——七套方法论是这门课**唯一能靠努力补上的部分**（区别于 C7 补不了）。短轴可量化、可补、藏不住；但也要认得出"这里该请真专家了"（复杂财评、重大法律风险），这也是能力半径的一部分。
