〇、开场（教练宣读，2′）

📌 本环节为研讨环节（不产交付包物件）——本讲就本组命题做启发式研讨，产出记进工作簿的“思考”区即可，不强塞交付物。下方的 💡 启发范例是标尺、不是模板：康养项目/教育督导项目/辣椒/草业项目做对了长这样，帮你把研讨聊到点子上、照结构想，别抄数字。

🎯 本坊目标：就本组命题研讨清楚 哪些关键环节可交给智能体放大（可替）、哪些必须人亲自扛（C7 客户关系/责任承担/价值判断/政治敏感度），并用三问判据把归侧理由说透——产出是研讨观点 + 一句话边界共识（我能靠智能体放大的是什么、我必须亲自扛的是 C7 哪几项），记进工作簿“思考”区。

🧭 过程方法论（本坊用的 FDE 方法）：C7 四项（客户关系/责任承担/价值判断/政治敏感度）· 三问判据（需身份？需立场？谁签字？）· 偷懒项/误判项自审。

📏 工作坊纪律（教练宣读） 1. 启发-执行：每步先点开“💡启发”看康养项目范例，再动手；不空想。 2. 时间盒：铃响即停，列环节/过三问都守时。 3. 终止铃：教练铃响，讨论立即停，进下一步。 4. 停车场：争不出的挂 parking lot，会后再议，不占时间盒。 5. checkout：每阶段末对照输出与验收标准。

🙌 工作坊宣言（齐读）：完成大于完美 · 团队大于个人 · 共识大于对错。

2.2 三问判据卡（贴在手边）

任一答案指向“人”，即归“必须人扛侧”： ① 这活需要一个身份才能做吗？（客户关系 / 政治敏感度） ② 这活需要一个立场才能拍吗？（价值判断） ③ 做错了谁签字？（责任承担） 三问皆“否”（不需身份、不需立场、错了能回退），才归“可替侧”。

2.3 你要带来的输入

一个你正在做或最近做过的真实项目（To-G / To-B 皆可）。列出它认知侧的 8–12 个关键环节（从调研到交付物）。没有在手项目的，用康养项目二期“微康养 60 站点运营方案”做替身。

三、分阶段脚本（每步：🔔任务 / 🔔输出 / 🔔难点 + 💡启发范例）

阶段一 · 拎关键环节 + 过三问研讨判侧（4′ + 12′）

步骤① · 定命题、拎几个关键环节当靶子（2′ + 4′）

🔔 任务：就本组命题（无在手项目可借康养项目二期“微康养 60 站点运营方案”当替身），一起把认知侧从调研到交付大致捋一遍，拎出几个值得研讨的关键环节当靶子，先不判侧。 🔔 输出：几个覆盖全链的关键环节（研讨靶子）——不追求列全 8–12 条，够聊到点子上即可。 🔔 难点/注意：靶子要尽量覆盖全链（别只盯写作/建模一段，“进门/拍板/签字”这类链尾环节最出洞见）；先别急着划侧，划早了会被直觉带偏。

💡 启发 · 点开看康养项目范例

康养项目认知侧全链环节（做替身时可照此颗粒度）：① 客户访谈/认知萃取 ② 102 事件整理归簇 ③ 7 角色画像 ④ 7 域切分 ⑤ 7 域本体五要素骨架生成 ⑥ 3835 行插件骨架编译 ⑦ 11 万字可研并行写作 ⑧ 26 图绘制 ⑨ 补 11 处地方文号/企业 SOP ⑩ 定站长 HIL 置信度阈值 0.75 ⑪ 守“赋能优化非替代”To-G 红线 ⑫ 交付物对客模板排版。启发点：链条要从“调研”一直拉到“交付/签字”——⑨⑩⑪ 这类“进门/拍板/签字”环节往往被漏在链尾，正是本讲要抓的人扛项。

步骤② · 就每个靶子过三问、一起研讨判侧（12′）

🔔 任务：拿 2.2 的三问，对每个靶子环节一起研讨——任一指向“人”就是“人扛”，否则“可替”；一时议不拢的先记“❓存疑”，这些争议点正是研讨富矿。 🔔 输出：各环节判侧的研讨观点（可替 / 人扛 / ❓）+ 命中哪一问的说法。 🔔 难点/注意：判据是“需不需要进门的身份/拍板的立场/签字的责任”，不是“难不难/活多不多”。别把“工作量大”（如“要写 11 万字”）当人扛——那恰是可替侧典范（三问皆否）。别把查得到的合规活划人扛、把查不到的文号划可替，这正好反了。

💡 启发 · 点开看康养项目范例

三问判侧示范（对照 2.1）： - 11 万字可研并行写作 → 三问皆否（不需身份、不需立场、错可回退重写），标 可替。工作量大 ≠ 人扛。 - 补 11 处地方文号 → 问①命中：需进某市医保局/民政局/政数局的身份逐项取件，标 人扛（政治敏感度/客户关系）。注意：这活“查不到”很难，但归人扛不是因为难，是因为“需要进门的身份”。 - 定站长 HIL 阈值 0.75 → 问②命中：要担“错误增收”的立场，标 人扛（价值判断）。 - 守“赋能优化非替代”红线 → 问③命中：做错是 FDE 签字担责，标 人扛（责任承担）。

启发点：同样“难”的两件事，“编译 3835 行骨架”是可替（可编译验证、错可回退），“补文号”是人扛（需身份）——区别在三问，不在难度。

阶段二 · 议理由 + 抠硬骨头（10′ + 5′）

步骤③ · 逐条议清一句话理由（10′）

🔔 任务：就每个靶子研讨出一句话理由，格式：“归 X 侧，因为【命中/未命中哪一问】”。说不出理由的环节，退回“❓存疑”继续议。 🔔 输出：各条归侧理由的研讨共识，明确指名命中/未命中哪一问。 🔔 难点/注意：理由是“感觉/经验”一律不算数——必须落到三问的具体某一问。含糊如“这个得人来做比较稳”要被同伴顶回去重议。

💡 启发 · 点开看康养项目范例

一句话理由范本（每条落到三问）： - “102 事件归簇 → 归可替侧，因为三问皆否（无需身份、无需立场、错可回退重跑）。” - “补 11 处文号 → 归人扛侧，因为命中问①（需进机关的身份取件，属政治敏感度）。” - “定 0.75 阈值 → 归人扛侧，因为命中问②（需担错误增收风险的立场，属价值判断）。” - 隐蔽项范例（加分）：“整理客户访谈纪要”看似可替，但决定哪句能写进对客文档、哪句是内部敏感信息这一判断命中问②（立场/政治敏感度）→ 该环节要拆成“整理=可替 / 定密=人扛”两层。

启发点：理由的价值在“指名哪一问”，不在结论；同一环节划哪侧可争，但理由必须落到三问。

步骤④ · 抠一个硬骨头一起吵（5′）

🔔 任务：从靶子里挑 1 个最没把握、最有争议的，全组一起吵它到底在哪侧——这条会带进复盘研讨。 🔔 输出：一个硬骨头的研讨观点（哪个环节 / 议下来归哪侧 / 命中哪一问 / 争议点在哪）。 🔔 难点/注意：挑真拿不准的（往往是“看起来可替、其实藏着身份/立场/签字”的隐蔽项），别挑一眼能定的凑数。

💡 启发 · 点开看康养项目范例

硬骨头论证范本（50 字）：“我最没把握的是第 ⑫ 条交付物对客模板排版——看似纯可替（美工活、三问皆否），但排哪些数据进对客版、哪些留内部触到问②立场，故拆成’排版=可替 / 内容取舍=人扛’。”——这种“看起来可替、其实一半人扛”的拆分，正是硬骨头该有的深度（对照教育督导项目/辣椒方案级项目里“对客材料复核”也是同类人扛闸，🟡 方案级，非实测）。

阶段三 · 自审偷懒项 checkout（3′）

步骤⑤ · 双向自审 + 议出一句话边界共识（3′）

🔔 任务：回看议成“可替”的项，讨论哪些其实是你们懒得让智能体做而非真可替；回看“人扛”的项，讨论哪些其实藏着未识别的身份/立场/签字；最后议出一句话边界共识。 🔔 输出：偷懒/误判的自审讨论 + 一句话边界共识（能靠智能体放大的是_；必须亲自扛的是_，对应 C7 哪几项）。 🔔 难点/注意：“可替”全满、无一存疑 = 没真自审。把“我懒得做”当“人扛”是本讲要打掉的头号错误——它会让你误判自己的能力半径。

💡 启发 · 点开看康养项目范例

自审示范：把“7 域本体骨架生成”标了人扛？——回看三问皆否、可编译验证，其实是懒得让智能体做/不信任平台，改回可替（这是短板，该补，不是边界）。反向：把“整理访谈纪要”标了可替？——其中“定密”命中问②，藏着人扛，要拆出来。边界结论范本：“这个项目里，我能靠智能体放大的是认知萃取→本体→并行写作全链（可替侧）；我必须亲自扛、无法外包的是补文号（客户关系/政治敏感度）+ 定 0.75 阈值（价值判断）+ To-G 红线签字（责任承担）——对应 C7 的客户关系、价值判断、责任承担、政治敏感度。”

四、checkout（研讨深度对照表）

本环节不产交付物，checkout 看的是研讨深度——不是有没有交出清单，而是有没有真聊到点子上。每阶段末 + 收尾各对照一次。

维度 ✅ 聊到位 ⚠️ 没聊透（要回去再想）
A 落到本组命题 研讨的靶子来自本组命题、覆盖调研→交付全链，不是空谈概念 泛泛聊“FDE 边界”，没落到自己命题的具体环节
B 判据严谨度 每条归侧都过三问、理由指名命中哪一问，是真判断不是感觉 只表态站哪侧不给理由，或理由停在“感觉/经验”
C 边界洞察力 议出 ≥1 条隐蔽的 C7（看似可替、实藏身份/立场/签字），不把“活多”误当边界 把“我懒得做”当“人扛”，或把 11 处文号类活当可替
D 自审诚实度 敢当众承认自己的偷懒项/误判项并改口 全说“可替”、无一处存疑，或全程没有一条自己的判断

研讨深度参照：四维都聊透、能挑出隐蔽项 = 看得清自己能力半径（L2 潜质）；议出 C7 但混着偷懒项 = 还在见习；把“懒得做”当边界、或全程没一条自己的判断 = 没进入研讨。 研讨红线：把“我懒得做”当“人扛”、把查不到的文号类活当“可替”、或全程没有一条属于自己的判断 —— 这三种情况说明还没真研讨。把偷懒当边界正是本讲要打掉的错误（C7 只能筛不能训，主张 4）。

五、复盘研讨（3 题，教练收口，18′）

  1. （偷懒 vs 人扛） 你清单里“必须人扛”的条目，有几条其实是你懒得让智能体做、被误判成人扛？反过来，有几条标了“可替”却藏着身份/立场/签字问题？
  2. （不能外包的论证） 假如老板要求你把一条“必须人扛”的活外包给智能体“提效”，你如何解释它不能外包？请用康养项目 0.75 阈值或 11 处文号做类比说服他。
  3. （C7 弱项） C7 四项（客户关系 / 责任承担 / 价值判断 / 政治敏感度）里你个人最弱的是哪一项？这门课能补吗？

教练收口锚点：题 1——把“懒得做”当人扛会误判能力半径，回收本步自审。题 2——引 0.75 阈值（价值判断，需担错误增收立场）/ 11 处文号（政治敏感度，需进门身份）说明“提效”提不掉责任与立场。题 3——引导承认 C7 弱项补不了（对齐主张 4“C7 只能筛选”）；敢说“我政治敏感度不行、这类项目我需要搭档”的学员给正向反馈——这是第 8 讲“装作 L2 才是危险的”的预演。

六、参考答案要点（讲师版 · 标“讲师专用勿发学员”）

⚠️ 讲师专用，勿发学员。

  • 本 Exercise 无标准答案，评的是判据使用，不是划侧结果。 同一环节划哪侧可争，但理由必须落到三问。理由是“感觉/经验”一律扣 B 维。
  • 最常见错误（重点抓）：
    • 把“工作量大”当“人扛”——如“要写 11 万字所以人扛”。错。11 万字并行写作恰是可替侧典范（三问皆否）。命中此错扣 C 维。
    • 把查得到的合规活划人扛、把查不到的文号划可替——正好反了。判据是“需不需要进门的身份”，不是“难不难”。
    • “可替”栏全满、无一存疑——说明没做第 5 步自审，扣 D 维。
  • 优秀样本长相：能指出一条“看起来可替、其实人扛”的隐蔽项。例：项目里“整理客户访谈纪要”看似可替，但决定哪句话能写进对客文档、哪句是内部敏感信息这一判断是政治敏感度（立场），须人扛——这层拆分给 C 维满分。
  • 研讨题 3 收口：引导学员承认 C7 弱项补不了（对齐主张 4“C7 只能筛选”）。敢说“我政治敏感度不行、这类项目我需要搭档”的学员，给正向反馈——这正是第 8 讲“装作 L2 才是危险的”的预演。
